## Task

I developed the calculation logic for metrics and a volume forecast for a plastics sorting company. The company wanted to display metrics and a forecast of incoming volumes in its web application. Management set the requirements, and the development team was responsible for implementation. The calculations lacked clear rules.

## Approach

I worked with management and the development team to clarify which requirements applied, what data was available and how the calculations should handle special cases. I documented the business rules and implemented them in Python and SQL as a reference.

I used historical data to test several approaches to volume forecasting against a simple baseline forecast. I checked the production calculations against the reference until both produced the same values. I handed over the code with reference data and technical documentation.

## Result

The web application adopted the code for the metrics and the volume forecast.
