## Areas of work

### Geodata and geo data science

I turn satellite data and geodata into datasets that can be used for analysis, and I train models on them. This covers spatial questions from a single address to a 10 m raster, including routes and tours.

Tools: Python, PyTorch, Landsat and Sentinel-2 satellite data, Google Cloud

Evidence: [Master's Thesis · Berlin's Heat at 10 m](/en/projects/berlin-lst-downscaling), [Routing Engine · Planning and Solver](/en/projects/routing-engine-solver), [urban-tree-transfer](https://github.com/spignotti/urban-tree-transfer)

### Collecting, preparing and analysing data

I find out which data really exists, prepare it and define the calculation logic. The result is KPIs and forecasts that can be checked against a reference.

Tools: Python, SQL, relational databases

Evidence: [KPI Reference](/en/projects/kpi-reference)

### AI workflows and automation

I use AI coding agents in software development, with clear rules, checks and reviews. This produces applications that run in daily operations and workflows that take over recurring work.

Tools: coding agents, GitHub Actions, Docker, Python

Evidence: [Routing Engine · Built with Agents, Run in Production](/en/projects/routing-engine-agentic), section "How I work"

## How I work

1. **Understand the business process.** I look at how the work is done today and talk to the people who do it. From this I derive rules, data and special cases.
2. **Plan.** I decide what gets built and what does not, and write it down as a task with acceptance criteria. Decisions that are not visible in the code get a short written record.
3. **Build with agents.** AI coding agents implement the tasks in separate working copies. The rules they follow live in the repository.
4. **Check.** Automated checks, a review and, for visible changes, a test in the running app decide whether a change is merged. I approve risky changes myself.
5. **Run it.** Releases, deploys, monitoring and backups are part of the work. Feedback from daily use becomes new tasks.
