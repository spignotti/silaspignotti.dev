# About

In my master's in geoinformation at BHT Berlin, I focus on remote sensing, geo data science and machine learning. Alongside, I build applications that run in daily operations and work on KPIs and forecasts for companies. I am interested in tasks where requirements, data, logic and implementation have to come together.
